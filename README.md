# AirCard

一个纯前端、隐私优先的卡面设计工具，由 **iOS夕颜** 重构维护。

## 功能

- 本地上传并裁剪卡面图片
- 参考图叠加对位
- 多 Logo 图层、拖拽、缩放、旋转与透明度调整
- Logo 去底与外描边
- ISO 7810 ID-1 卡面比例
- PNG 导出
- 中英文界面
- 无广告、无站外跳转、无需登录
- 图片处理全部在浏览器本地完成

## 使用

直接打开 `index.html` 即可使用，无需安装依赖或后端服务。

## 隐私

图片、Logo 与导出内容均在浏览器本地处理。本项目页面通过 CSP 禁止外部网络连接。
